# Fantasy Liga Elite V37 – Real Fan Media

V37 kann pro Team echte lokale Fanvideos und Audiodateien speichern und passend zum Spielausgang abspielen.

- Teams → Bearbeiten → Reale Fanszenen & Fangesänge
- Kategorien: Heimsieg, Auswärtssieg, Unentschieden, allgemein, Fangesänge/Trommeln
- Medien bleiben lokal in IndexedDB und werden nicht in Karriere-Backups kopiert
- Nach Abpfiff wird passend zum Sieger eine andere Datei ausgewählt
- Ohne Medien bleibt die Stadion-TV-Sequenz als Fallback erhalten
