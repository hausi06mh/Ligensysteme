V69 baut auf V68 auf und synchronisiert Feld, Ticker und Statistiken. Vorab erzeugte Fake-Chancen/Ecken wurden entfernt. Chancen erscheinen erst nach einer sichtbar abgespielten Abschluss-Szene.
